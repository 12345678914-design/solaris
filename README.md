# instrucciones
* Descargar WSL, la distribucion ArchLinux
* Descargar e instalar las 8 herramientas dentro de arch usando pacman
* conectar WSL en Visual Studio Code usando ">" en la barra superior del IDE escribir wsl: conectar
* usar la terminal de arch que se encuentra disponible en bash+, hacer click a + y escoger arch
* usar comando ```make clean``` para limpiar build
* usar comando ```make``` para crear la build
* usar comando ```make run``` para correr el sistema en qemu
